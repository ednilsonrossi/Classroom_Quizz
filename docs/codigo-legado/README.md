# Código Legado — Criação de Quizzes

Esta pasta reúne arquivos da implementação anterior do módulo de criação e visualização de quizzes do Classroom Quiz, desenvolvida com **JavaScript, Flask e templates Jinja2**. Também inclui arquivos de estilização, formulários implementados com bibliotecas do Flask e rotas auxiliares utilizadas nessa versão.

Essa implementação foi utilizada antes da migração da interface para React. Ela contém funcionalidades como criação e edição de questões, gerenciamento de alternativas, validação de dados, integração com a API e visualização dos quizzes.

## Objetivo

O código é mantido exclusivamente para **consulta e referência histórica**, permitindo compreender a evolução do sistema e recuperar detalhes da implementação anterior, se necessário.

**Importante:** esta implementação não corresponde à versão atual do sistema e não deve ser utilizada como referência para novas funcionalidades sem antes verificar a arquitetura vigente.
